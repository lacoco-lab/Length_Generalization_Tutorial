# Version 2 (experimental)

Self-contained alternate tutorial with drag-and-drop C-RASP program editing.

This directory does **not** replace the main tutorial at `site/index.html`.

## How to start

From the repository root:

```sh
python3 -m http.server 8000 --directory site
```

Then open:

- Main tutorial: http://localhost:8000/
- Version 2: http://localhost:8000/version2/
